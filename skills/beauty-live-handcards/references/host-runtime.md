# 宿主工具与能力适配

## 当前会话能力
读取实际可用工具的说明，记录本次采用的生图、参考图编辑、读图、文档和导出能力。调用名称和参数以当前宿主为准，不复制 Codex 专用工具名，不猜测接口。
- 有生图且支持参考图：使用当前产品真实包装、Logo与用户授权风格图，明确各图角色。
- 只有文生图、没有参考图编辑：可完成文案和布局准备；包装准确性或局部修字受限时明确缺口，不将失真的包装图判为通过。
- 无图片生成或编辑工具：交付已核事实、锁定文案和可执行提示词，状态为“待生图”；不拿HTML截图或空白框冒充摄影/3D成品。
- 无视觉读取能力：图可生成，但中文逐字及包装审阅状态为“待人工复核”；脚本通过不能代替看图。
- 有文档排版能力：原始PDF页面可嵌入排版后导出，不能让模型重画签章和报告。

优先使用用户已有的宿主工具与模型配置；不改登录凭据、默认模型、权限策略或连接器，不为完成任务私自新增付费服务。生成任务按本次用户授权范围执行。

## 文件和状态
技能目录只存规则、参考文档与脚本。用户素材、事实表、提示词、图片、PDF和审阅记录存到本次工作目录，避免进入可分享的技能包。参考路径相对SKILL.md解析，输入/输出路径使用实际工作目录。
已调用技能、已生成图片、已通过视觉复核分别记录。安装成功只证明文件可读取，不保证图片效果与其他宿主完全相同。
