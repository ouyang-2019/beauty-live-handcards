# 单页达人手卡：场景先行、原料讲透

视觉参考由本次用户提供；无参考时按下述版式起稿。

用于single_card与full_set_plus_card。单页是一款产品的完整讲解卡，不是货盘表，也不是只放一句标语的海报。

## 信息结构与排版
默认横版约1.42:1。左约三分之一放真实包装参考主视觉、品牌、规格与已核零售价；右约三分之二放高密度讲解。奶油白、香槟金为可选基调，产品自身色彩决定识别差异。正文落在干净浅底上，深色字，原料名和关键数字局部强调；光泽、花朵、水滴不压字。

正文顺序：产品全名 → 痛点与使用场景 → 一句话卖点 → 3至5个编号卖点（功效、原料机制、配方特点、质地使用特点、对应证据）→ 用法与简明来源注。痛点场景必须是最先读到的正文，不藏在底部。痛点段要像直播口播提词：先点出具体尴尬或需求，再给出护理切入点，例如“空调房久待脸发紧”“上妆鼻翼卡粉”“洗手后指缘干裂”“头皮油、发尾打结难梳”。无报告时用已核实产品特点替代证据区，不做虚构证书或空白报告占位。未知价格用规格/使用特点占左下价格位置，不编价，也不让缺价阻断生图。

场景写成“具体时刻＋可感知困扰＋护理需求”：空调房久待脸发紧、上妆鼻翼卡粉、洗手后指缘干、发尾打结难梳等。按品类重写；去屑洗发水、卸妆、洗衣液不能套脸部细纹话术。不把场景假设写成本品已验证的改善结果。

## 原料爆点研究与话术
先确认真实配方包含该原料，再查原始研究、原料生产商官方资料或权威技术资料。保存精确来源URL、访问日期、原料身份、研究对象及条件。相同原料可复用本批已核研究；新机制、新原料另查。用户允许网络研究，不代表授权照搬营销夸张主张。

每个重点原料写出：**准确名称 → 有特色的作用/机制 → 易懂比喻 → 对应护理价值**。不要停在“含XX，丰富配方、值得认识”。原料特色段要写出“为什么它值得讲”，例如把成膜、亲水、油脂相容、角质层护理、酶抑制、细胞模型等机制转成主播能读懂的表达。比喻服务于机制，不能替代证据。避免所有产品都写同样的“水润、舒缓、年轻”。

表达方式示例（不是所有产品通用配方）：
- 透明质酸钠：亲水保湿，可比喻“水润蓄水网”。未核分子量时不说分层渗透或直达真皮。
- 甜菜碱：有机渗透质，参与水分平衡，可比喻“水分平衡员”。
- 泛醇：B5前体，原料资料支持角质层水合与减少经皮水分流失，可比喻“柔润后盾”。
- 肽类原料：按已核原料研究解释其特色，点明研究对象，再承接本品的日常护理场景。

把原料科普与成品实测分开。文献的配比、浓度、试验周期、倍数不能挪到本品。供应商网页不是本品原料供应链证明；不据此写进口、专利、某大牌同源。成分同名也要核查INCI及提取物/滤液/溶胞物区别。不要用“注射替代”“重塑皮骨”“逆龄若干岁”等无据承诺增添感染力。

香型与成分分开：产品叫“乳木果香型”不能单凭名字写“蕴含乳木果精华”。原料图须按真实原料身份绘制，不能只按中文俗称联想：牛油果树果脂（乳木果脂/shea）不画成鳄梨的绿色果肉和大果核；雨生红球藻不要当普通海藻食材示意。已知为香型但配方未核时，讲香气、使用时刻与已核质地，不添具体添加量或原料功效证明。

报告数据进入单页时，写成“指标全称＋数值＋证据类型＋关键条件”，正文用正向语言承接检测亮点。例如体外称重法保湿率、弹性蛋白酶抑制率、人皮脂腺细胞脂质相对含量、人体问卷认同率要分别表述，不能互相替换。试验类型、样品原液或10%浓度等关键条件与对应数据成组、清晰可读；来源编号可放简注。指标和条件已标清时，不再另列“不是人体改善率”等否定式说明。单页空间有限时，优先放最能支撑卖点的一至三条数字，其余留给独立报告页。具体写法见[推广表达与证据标注](promotion-copy.md)。

## 营销机制升级：每款一个能记住的理由

当用户要求“更精彩的营销话术、噱头、技术看点”时，先逐款写主记忆点，再写3至5个完整模块。优先用“原料的真实特点＋容易理解的比喻＋使用中的好处”：例如卸妆油的先溶后乳化、保湿原料的蓄水搭配、洗发与护发的头皮发尾分区、礼盒的多步骤搭配。清洁品不套皮肤抗老机制，套盒不把各单品原料或报告一概相加。

“植物与发酵双路养护”“柔润保护衣”等可以是讲解名称，不能称作已获专利的技术。资料只列技术名而没有原理时，不为该名称发明纳米递送、靶向透皮或胶原再生机制。品牌货盘列出的原料可以注明来源后用于解释，但不能把简称擅自补成未经核定的INCI，或推断礼盒每一支都含相同原料。完整成分表缺失时仍要利用现有可靠资料做有内容的卖点，不把整页退化成香型清单。

分开保存**上图成稿**和**制作依据**。成稿是顾客可阅读、主播可直接念的句子，不出现“直播可讲、画面可以、不要写、没有报告就、资料边界、更好成交”等工作指令。证据缺口、规格冲突及审核意见放生产记录；未解决匹配关系的报告不进入成稿。必要的试验性质和条件在数据区简明保留，不拿“没有报告”或反复否定说明凑卖点模块。

先审文本，再生图；多人并行时由主负责人审核各款具体内容。检查技术点是否真的对应这款原料或结构、比喻是否导致错误作用深度、是否把他人的原料研究说成本品实测。通过后直接批量制作用户已授权的范围。最终逐图核中文品牌、产品全名、原料名、价格规格与数据；直接保存原生生成图，记录源文件路径和哈希，不能以旧图存在冒充本轮改版完成。

## 新增备案与配方：重选明星原料

用户补充备案凭证或定量配方时，重新核对已有营销主轴，不能只在旧页上追加几个成分名称。逐款建立“备案产品全名/编号 → 配方文件及工作表 → 在售包装和规格 → 报告样品”的对应表；相似名、套盒各单品、规格差异单独记录。备案凭证证明产品身份与列示成分，不等于监管部门认证产品功效。

优先读取Excel单元格，保存坐标、原文与文件哈希。原料加入量、复配内组分占比、成品中该INCI贡献量分栏：成品贡献百分数＝原料百分数×组分百分数÷100。合并单元格要沿组继承，同一INCI跨原料可求和但保留明细。发酵液、植物提取物等本身仍是混合物，折算出的INCI含量不能改称纯活性、纯固形物或活菌浓度。只有成分排序而没有定量配方时，不猜百分比。

按“真实含量与配方作用、证据匹配、产品差异、用户指定重点”选1至2个主角；把大部分解释和视觉权重给主角，其他原料作为协同配角。浓度不是唯一标准，但微量名贵成分不能挤掉承担主要作用的原料。若新配方推翻旧主轴，直接改写：例如表活与甘油主导的沐浴产品不能因名字带油就讲以油溶油；四支手霜不可仅凭货盘概述说每支都含二裂或大豆。

每个主角用“可记住的讲解标题 → 精确原料身份/可靠含量 → 为什么值得讲 → 易懂作用机制 → 对应使用需求”写成完整口播；不得用‘高级、黑科技、明星’空泛形容替代说明。保留原料机制与成品验证的区别，未提供成品检测时不生成数字功效承诺。

### 将技术点写成能直接念的句子

一段通常完成三件事：点名主原料/配方特点，解释它在这款中的作用，再回到一个具体使用场景。模块标题可以有画面感，正文必须能讲清，不只重复标题。篇幅不足时减少次要成分，不把所有原料平均塞满。

- 弱：“甄选多重明星成分，科技感满满。” 强：“二裂发酵滤液＋HEPES做双主角，再由烟酰胺与水润配方承接，围绕熬夜后粗糙、暗哑的护理需求展开。”真实含量可紧邻名称展示；作用解释仍需本品或对应原料依据。
- 弱：“保湿抗皱成分丰富。” 强：“面膜做集中贴敷，肌底液承接水润调理，面霜以柔润肤感收尾；三件各有分工，日常护理顺序更清楚。”这是搭配理由，不是组合效果倍增试验。
- 弱：“玫瑰、甜扁桃、乳木果四款香型。” 强：在四款配方已核时，分别说明油脂/保湿组分与肤感，再把香气和洗手后、办公桌、随身携带等时刻连接；不能让香型描述代替原料与功效介绍。

这些是表达方式示例，不是其他产品可直接套用的配方事实。用户要求“更有噱头”时提高具体度、节奏和比喻辨识度；不靠“院线同效、直达肌底、胶原再生、倍增”代替资料缺口。

“轻薄不黏、清爽、长效、适合厚敷、每日频次”等同样是需要依据的肤感或用法信息，不因它们没有百分数就随意补写。可建议摆放在办公桌或随身携带等场景，但不能据香型推断某支更轻盈、某支更适合厚涂。上图句子写给消费者，避免“这款能讲的是……不是把别人的数据搬来”这类制作解释；该内容应留在依据记录。

### 大品牌、明星产品同成分的核验

只使用品牌官方具体产品页/官方包装的完整INCI，记录产品全名、地区/版本、访问日期、链接与匹配成分。逐字符核身份，尤其滤液FILTRATE、溶胞产物LYSATE、发酵物FERMENT、提取物EXTRACT及衍生物不可互换。真实供应链证据缺失时写“某产品官网配方也列有同名成分”或“同名INCI参照”，不能升级为同供应商、同源、同专利、同浓度、同配方或同功效。竞品研究和临床数字不迁移到本品，不假借竞品标识背书。

同名成分比较以本次所核原始资料为准，成分身份或版本不匹配时不建立等同关系。

资料更新后的交付逐款区分“新资料改版”和“沿用已核版本”，不把复制旧图说成本轮重制。补齐新报告页，重新检查所有主数字、原料名和包装字，更新PDF、ZIP及SKU变更清单。

### ppm展示偏好与数字复核

用户希望用ppm时，将有定量证据的成品配方含量统一换算：1%=10,000ppm；算术示例：0.2%=2,000ppm、0.005%=50ppm（仅示范换算，不代表任何产品配方）。用十进制定点计算，不漏四个数量级；复制浓度、复配折算、ppm转换分三步保留来源。主体数字旁写“配方含量”，底注保留换算关系。是否采用ppm以本次用户要求为准。

ppm只是单位换算，不表示添加量增加或功效更强；不借数字变大把微量辅料包装成高含量核心原料。只有INCI而没有定量表的产品不编ppm。发酵液/提取物的ppm仍不等于纯活性。成品报告的改善率、酶抑制率、问卷认同率维持百分比；试验样品浓度维持报告条件并明确标识，不能混作商品配方添加量。修改时核对同一数字在标题、正文、图注、脚注和源稿中的所有重复位置，再同步PDF与ZIP。

“全部改ppm”的展示偏好也只应用于有依据的配方含量。试验样品浓度默认保持原报告单位；若确有技术解释需要等值换算，原条件与换算值并列并明确标为测试浓度，不放入配方添加量卖点。指标结果不能换成原料ppm。

## 图片与文字质检（执行）
包装外形、中文品牌、英文标识、完整品名及规格锁定。生图前实看真实产品源图；旧生成图只作风格参考。包装不能变空瓶或仅留装饰符号。整图和200%重点区域逐字比对；检查同形字、少字、拉伸、重复标点、微字乱码、标题裁切、背景压字。对比价格、单位、数据、指标、人体/体外/问卷属性。注册符号无来源不增加。

局部错误先定点修复，冻结已通过部分；两次仍失败时简化布局、扩大包装标签、改用更清晰产品角度。仍无法核验的页如实记为待核，不全批宣称通过。每次改图重做对应检查，记录最终文件哈希。页脚可简洁，原料比喻不能靠难读小字修补主要文案中的虚假承诺。

## 文件交付
single_card：每产品文件夹保存`01_单页直播手卡.png`；整批附产品目录清单、资料缺口、预览PDF、ZIP。保留提示词、研究来源与实际质检记录于生产资料目录。
full_set_plus_card：建议将单页命名`00_单页直播手卡.png`，原模块图顺序保留；PDF/ZIP必须同时包含单页和模块。单页无需机械塞入每项报告全文。
实际像素尺寸如实记录，不把插值放大叫原生4K。

## 制作途中新增功效报告
按最新资料更新原有“缺报告”结论。比较产品全名、规格、配方/更名证明、委托样品、试验方法与报告日期；同名不同规格不能自动对应。记录与旧文件的哈希是否重复，不能把重复报告称为新增证据。
用户要求补报告页时，即使当前是single_card模式，也在匹配产品下增补独立报告页，并将经核关键数据同步进单页。这是本轮明确追加的交付范围，不因此重做全部模块。
报告页采用原PDF页/真实局部嵌入＋清晰指标解释；严禁生图模型重绘机构、签章、表格、证书。区分体外保湿率、人体含水量变化、酶抑制率、问卷认同率。报告名称与当前SKU不完全一致时，默认只列为“待核可用”，除非已有包装、备案、更名或同配方资料证明对应；例如不同名称、不同规格的面霜需要对应证明。未匹配报告放生产资料的待核清单，不移花接木到相似产品。新增报告整合后重核PNG、PDF、ZIP与索引。

回填时逐项核对时间点：1/2/4小时不能套成2/4/8小时；“细胞内脂质含量为空白对照的75%”不能改成“降低75%”。试验浓度、配方添加量、原液、阳性对照有效性阈值分栏记录。保留样品批号、规格、结论原页号及原PDF，报告页展示的送检规格不得冒充在售规格。

批量协作须限定产品编号和文件所有权；审核人只读，不得重绘全批或覆盖其他产品。整批打包仅由主负责人在最终哈希核验后执行，历史中间导出另存，避免占位图或旧版本混入正式包。原生生成、文档排版、人工复核分别记录，不能用文件存在或源图曾生成证明最终成品合格。
