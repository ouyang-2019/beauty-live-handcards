# Prompt examples · Beauty Live Handcards

[English README](../README.en.md) · [Installation](installation.en.md) · [中文示例](usage.md)

These examples are written in English and keep the artwork copy in Chinese to match the supplied product materials.

## Start with three draft cards

```text
Use beauty-live-handcards for the two products in this project directory.
Create one single-page livestream card per product, plus one combined card:
three separate PNG files.
Highlight use scenarios, actual ingredients and supported test findings.
Preserve the original packaging, logos, product names and sizes.
Review the Chinese text, packaging and specifications before delivery.
```

## Full product image set plus one card

```text
Use beauty-live-handcards to create a complete image set for this product,
plus one single-page creator/livestream card containing the key information.
Select the modules based on the provided materials.
Use the 3D visual to explain this product's specific ingredient/action story.
Use the real report pages when a report module is included.
Keep the artwork copy in Chinese. Deliver PNG, PDF and ZIP files.
```

## Revise with a new formula or report

```text
Use beauty-live-handcards to revise the existing artwork with the new formula
and matching reports.
Re-select the lead ingredients and selling points using the updated inputs.
Review the data and Chinese copy, and refresh all delivery files.
Keep previous versions and source records in the project directory.
```

## Improve promotional copy

```text
Use beauty-live-handcards to improve the promotional copy on these cards.
Make the use scenarios, ingredients and supported test highlights easy to read.
Keep the metric name, test type and necessary conditions beside each result.
Save production review notes in the working materials.
```

## Create a card without an efficacy report

```text
Use beauty-live-handcards to create a single-page card from the real packaging,
ingredient list and known application instructions.
Focus on the information that is available.
Record missing prices or reports in the production notes.
Keep the artwork copy in Chinese.
```
