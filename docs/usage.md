# 请求示例

[English](usage.en.md)

## 先做三张试稿

使用 beauty-live-handcards，为当前目录两个产品各制作一张单页直播手卡，再制作一张双品综合手卡，共三张PNG。突出使用场景、真实原料和检测亮点，检查包装、中文和规格。

## 单品整套加手卡

使用 beauty-live-handcards，为当前产品制作完整模块套图，并额外输出一张信息完整的单页达人手卡。模块依据资料选择，功效3D要解释该产品的具体作用，报告页嵌入真实原页。交付PNG、PDF和ZIP。

## 新资料改版

使用 beauty-live-handcards，用新增配方和报告重新选择主原料与卖点。修改当前成稿，检查数据和中文，更新全部交付文件。保留历史版本与来源记录。

## 文案表达优化

使用 beauty-live-handcards，优化当前手卡的推广正文。把场景、原料和检测亮点讲清，数字旁保留指标名称、试验类型和关键条件，审查备注存入制作资料。

## 无报告

使用 beauty-live-handcards，根据真实包装、成分表和已知用法制作单页手卡。发挥已有资料的价值，缺价格或报告写入制作记录。
